# Netcraze Stock

Публичная витрина актуального наличия Netcraze по городам.

- адаптивный каталог;
- поиск по моделям;
- фильтр по городу;
- остатки по каждому городу и общий остаток;
- автоматическое обновление каждые 15 минут;
- источник, учетные данные и закупочная информация не публикуются.

## Синхронизация

Workflow `Update Netcraze stock` получает данные из закрытого API/feed через GitHub Secrets и записывает только очищенный `data/stock.json`.

Поддерживаются два варианта конфигурации:

- `STOCK_FEED_URL` (+ при необходимости `STOCK_FEED_BEARER`);
- `SUPPLIER_API_URL` (+ `SUPPLIER_API_TOKEN`, при необходимости `SUPPLIER_API_METHOD` и `SUPPLIER_API_BODY`).

На публичную страницу попадают только название модели, артикул, город, количество и время обновления.
